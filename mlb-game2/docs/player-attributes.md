# 선수 능력치·성장 설계 (v0.3)

> 요구사항 명세 3.2(선수 생성)·3.5(훈련)·3.6(시상)의 상세 설계. 수치는 밸런스 설정(`game.balance.*`)으로 조정 가능하게 구현한다.

## 1. 기본 원칙
- 능력치 범위 **1~100**, 정수
- **성장은 확정적:** 훈련 1회 = 내가 고른 능력치 1개 **+1**. 랜덤·체감 없음
- **시작점은 고정:** 같은 학력(고졸/대졸)이면 모든 선수가 똑같은 능력치로 시작
- **종합(OVR) = 포지션 능력치 11개의 단순 평균** → 어디에 투자하든 +1 투자 시 OVR은 항상 +1/11
- 내 선수: 모든 능력치 상한 100, 전부 공개 / 다른 선수(NPC·다른 유저): 잠재력 완전 숨김
- **함정 능력치 금지:** 11개 모두 시뮬레이션 결과(기록 지표)에 직접 연결된다. 어떤 능력치에 +1을 해도 기록이 달라져야 한다
- 좌/우 상성은 시뮬레이션의 고정 보정으로 처리하고, 투수만 "좌우 대응"으로 반대손 불리함을 줄일 수 있다

## 2. 능력치 개수 산정
```
시즌당 훈련 기회 = 54회 (시리즈마다 1회)
목표: 훈련만으로 시즌당 OVR +5
→ 능력치 개수 = 54 ÷ 5 ≈ 11개   (54 ÷ 11 = 시즌당 OVR +4.9)
```
타자·투수 모두 **11개**로 맞춘다.

## 4. 시작 능력치 (랜덤 없음, 기본값 + 자유 배분)
| 구분 | 나이 | 기본값 (11개 모두) | 자유 배분 | 시작 OVR | 비고 |
|---|---|---|---|---|---|
| 고졸 | 18세 | **25** | **55포인트** | 30 | 성장 기간이 4년 더 김 |
| 대졸 | 22세 | **35** | **55포인트** | 40 | 고졸 대비 약 2시즌 앞서 시작 |

- 55포인트 = 11개 × 5. 기본값을 5씩 낮추고 그만큼을 유저가 원하는 곳에 배분 → 시작 OVR은 배분 방식과 무관하게 항상 같음
- 배분 규칙: 55포인트를 **전부 사용**해야 생성 가능, 능력치 하나에 **0~25포인트** (`allocation-max-per-attribute`)
  - 예) 고졸 거포: 파워 25 + 갭 파워 25 + 컨택 5 → 파워 50, 갭 파워 50, 컨택 30, 나머지 25
  - 예) 고르게 배분: 모든 능력치 +5 → 모두 30
- 같은 학력·같은 배분이면 누구나 똑같은 능력치 (랜덤 없음)
- 추가 포인트 구매는 재화 시스템(M6 "시작 스탯 구매")에서 이 배분 포인트를 늘리는 방식으로 확장
- 컴바인·드래프트는 능력치를 바꾸지 않음 (지명 순위·팀·시작 레벨만 결정)

## 5. 스탯업 기회 (= +1 포인트)
모든 성장 수단은 **"+1 기회"** 단위로 통일한다. 기회 1개 = 원하는 능력치 1개 +1.

| 수단 | 시점 | 기회 수 |
|---|---|---|
| 훈련 | 시리즈 종료 후마다 (즉시 사용) | 1 |
| 월간 시상 | 매월 말 (4~9월, 9시리즈마다) | 상 1개당 1 |
| 시즌 시상 | 정규시즌·포스트시즌 종료 후 | 상별 차등 (아래 표) |

- 시상으로 받은 기회는 **보유 포인트**로 쌓이고, 원할 때 사용 (시즌 넘어 이월 가능)
- 능력치가 100이면 해당 능력치에는 사용 불가

### 5.1 월간 시상 (각 +1)
| 상 | 대상 |
|---|---|
| 이달의 선수 (타자) | 리그(AL/NL)별 1명 |
| 이달의 선수 (투수) | 리그별 1명 |
| 이달의 루키 | 리그별 1명 (신인 자격자) |
| 이달의 구원투수 | 리그별 1명 |
| 마이너리그 이달의 선수 | 레벨(루키~AAA)별 타자·투수 각 1명 |

- 한 선수가 한 달에 받을 수 있는 최대: 2개 (예: 이달의 선수 + 이달의 루키)
- 시즌 최대 약 +12 → OVR 약 +1.1

**밸런스 기준**
| 시즌 유형 | 훈련 | 월간 | 시즌 시상 | 합계 | OVR 상승 |
|---|---|---|---|---|---|
| 평범한 시즌 | 54 | 0 | 0 | 54 | +4.9 |
| 좋은 시즌 (올스타, 월간 2회) | 54 | 2 | 1 | 57 | +5.2 |

→ 시상 보너스는 최대 약 +40% 수준으로 제한되어 훈련이 성장의 중심을 유지

### 5.3 시상 판정 (M4-3 구현, `AwardService`)
| 시점 | 메이저리그 (같은 리그 NPC 와 비교) | 마이너리그 (레벨별 가상 유망주 30명과 비교) |
|---|---|---|
| 9시리즈마다 (월간) | 이달의 선수(타자) / 이달의 투수(선발) / 이달의 구원투수(마무리) / 이달의 루키 | 마이너리그 이달의 선수 |
| 27시리즈 후 | 올스타 (같은 포지션 타자 2위 이내, 선발 6위·구원 4위 이내) + 올스타전 MVP 8% | 마이너리그 올스타 (비교군 3위 이내) |
| 54시리즈 후 | MVP·실버슬러거·골드글러브(타자) / 사이영상(선발) / 올해의 구원투수(마무리) / 신인왕 | 마이너리그 올해의 선수 (시즌 절반 이상 마이너) |

- 판정 점수 (리그 평균 대비 실점 가치에 가까운 지표, 비교 대상 전원보다 높으면 수상)
  - 타자 = 타석 × (OPS − .720) / 2.2 + 수비로 막은 실점 + 0.2 × 도루 (실버슬러거는 수비 제외, 골드글러브는 막은 실점만)
  - 선발 = (4.40 − ERA) × 이닝/9 + 0.03 × 탈삼진 + 0.3 × 승
  - 구원 = (4.00 − ERA) × 이닝/9 + 0.3 × 세이브 − 0.5 × 블론세이브
- 최소 표본: 월간 60타석·20이닝(선발)·5이닝(구원) / 시즌 400타석·120이닝·40이닝 / 신인왕 250타석·60이닝 / 골드글러브 100경기
- 신인: 이전 시즌까지 메이저 시리즈 15개 미만 (NPC 는 서비스 0년)
- 메이저 상은 메이저에서 뛴 기록만, 마이너 상은 그 달(시즌) 소속 레벨 기준. 승격·강등보다 먼저 판정
- 수상하면 스탯업 포인트(5.1·5.2 표) 적립 + 수상 보너스 수령 원장 기록. 재기상·포스트시즌 MVP 는 M4-4/M4-5
- 포인트 사용: 시즌 허브의 "스탯업 포인트" 패널에서 언제든 능력치 +1 (`stat_point_logs` 기록)

## 9. 저장 구조
- `player_attributes(player_id, attr_code, attr_value INT)` — 선수당 11행
- `player_pitches(player_id, slot, pitch_type)` — 투수가 고른 구종 3개 (슬롯 2~4, 포심은 저장하지 않음). 능력치 아님
- `player_stat_points(player_id, balance)` + `stat_point_logs(player_id, source, amount, attr_code, created_at)` — 시상 보너스 적립·사용 이력
- 능력치 코드는 Java enum(`Attribute`)으로 관리
