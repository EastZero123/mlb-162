# 나만의 야구선수 키우기 — 요구사항 및 기능 명세 (v0.2)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 야구 선수 육성 시뮬레이션 (싱글 플레이 + 랭킹) |
| 핵심 루프 | 선수 생성 → 드래프트 컴바인 → 드래프트 지명 → **[시리즈 즉시 시뮬레이션 → 훈련(능력치 1개 +1)]** 반복 → 시즌 종료 정산 → 다음 시즌 … → 은퇴 |
| 플레이 방식 | 경기 중 조작 없음. 시리즈 단위로 결과가 즉시 산출되고, 플레이어는 **시리즈 사이의 훈련 선택**으로 선수를 성장시킨다. 진행 횟수 제한 없음(에너지·일일 제한 없음) |
| 성장 원칙 | **훈련 선택만으로 성장** — 재화·아이템으로 능력치를 올리는 경로는 MVP에 없음 (재화 시스템은 확장 여지만 설계, 7.1 참고) |
| 플랫폼 | 웹 브라우저 (PC 우선, 모바일 반응형) |
| 기술 스택 | Java 21 + Spring Boot 3 단일 애플리케이션 + MySQL 8 |

## 2. 핵심 게임 흐름

```
회원가입/로그인
   └─ 선수 생성 (이름, 포지션, 투타, 고졸/대졸 — 시작 능력치 고정)
        └─ 드래프트 컴바인 (테스트 4~5종 → 컴바인 점수)
             └─ 드래프트 (점수 + 랜덤 → 라운드/팀/계약금/시작 레벨 결정)
                  └─ 시즌 진행
                       ├─ 시리즈 시뮬레이션 (3~4경기, 즉시 결과 + 박스스코어)
                       ├─ 훈련: 능력치 1개 선택 → 확정 +1
                       ├─ 월말: 월간 시상 → 스탯업 기회 적립
                       ├─ 승격/강등 판정 (루키 → A → AA → AAA → 메이저)
                       └─ (반복)
                  └─ 시즌 종료: 시상, 연봉/계약, 나이 증가·노화, 랭킹 반영
                       └─ 은퇴 → 커리어 기록 확정, 명예의 전당 점수
```

## 3. 기능 요구사항

### 3.1 계정 (AUTH)
- FR-AUTH-01 아이디·비밀번호 회원가입 (비밀번호 BCrypt 해시 저장)
- FR-AUTH-02 로그인/로그아웃 (세션 기반, Spring Security)
- FR-AUTH-03 닉네임 설정 (랭킹 표시용, 중복 불가)
- FR-AUTH-04 계정당 활성 선수 슬롯 3개. 은퇴 선수는 슬롯을 반납하고 기록은 영구 보관

### 3.2 선수 생성 (CREATE)
- FR-CRE-01 기본 정보: 이름, 등번호, 국적(미국/일본/대만/한국), 출신 학교 지역(미국 동부/서부/남부/북부, 해외 — 실제 학교명은 받지 않음), 고졸(18세)/대졸(22세) 선택 — 시작 능력치와 성장 기간 차이
- FR-CRE-02 포지션 선택: 투수(선발 SP / 마무리 CP) 또는 야수(C, 1B, 2B, 3B, SS, OF) 중 하나. 투타 겸업(이도류)은 허용하지 않음
- FR-CRE-03 투타 선택: 우투우타/우투좌타/좌투좌타/스위치 등
- FR-CRE-04 시작 능력치는 랜덤 없이 기본값 + 자유 배분: 기본값 고졸 25 / 대졸 35(11개 동일)에 55포인트를 전부 배분(능력치당 0~25). 시작 OVR은 고졸 30 / 대졸 40으로 동일. 투수는 포심 외 구종 3개 선택(캐릭터 설정)
- FR-CRE-05 잠재력: 내 선수는 모든 능력치 상한 100으로 전부 공개, 다른 선수(NPC·타 유저)의 잠재력은 완전 숨김

**능력치 (1~100, 타자·투수 각 11개, OVR = 11개 단순 평균)** — 상세는 [player-attributes.md](player-attributes.md)

| 구분 | 능력치 |
|---|---|
| 타자 | 컨택, 삼진 회피, 선구안, 파워, 갭 파워, 주력, 도루, 수비, 송구, 클러치, 내구성 (포수도 동일, 수비·송구를 포수 방식으로 해석) |
| 투수 | 구속, 제구, 결정구, 무브먼트, 땅볼 유도, 체력, 투구 효율, 위기 관리, 좌우 대응, 회복력, 내구성 (SP·CP 공통, 체력·투구 효율·회복력은 보직별 해석) |
| 구종 | 능력치 아님. 포심 + 3개 선택, 하이라이트 연출용 |
| 상태값 | 컨디션, 피로도, 부상 (성장과 무관) |

### 3.3 드래프트 컴바인 (COMBINE)
- FR-CMB-01 테스트 종목 (포지션별로 다름)
  - 야수: 60야드 대시, 배팅 프랙티스(타구 속도), 수비 드릴 처리율(포수는 팝타임), 송구 속도
  - 투수: 최고 구속, 제구 테스트(20구 중 스트라이크), 불펜 피칭 스카우트 평가, 구위 유지 투구 수
  - 공통: 스카우트 인터뷰(선택지형 이벤트 → 스카우트 평가 보너스)
- FR-CMB-02 각 테스트는 능력치 + 당일 컨디션 편차로 기록 산출 (간단한 연출 애니메이션 + 결과 수치). **컴바인은 능력치를 바꾸지 않고 드래프트 결과에만 반영**
  - 당일 컨디션: 최악 −8 / 나쁨 −4 / 보통 0 / 좋음 +4 / 최상 +8 (확률 10/20/40/20/10%), 종목마다 추가 편차 ±10 이내
- FR-CMB-03 종합 점수 = 종목 점수 평균 + 인터뷰 가산점(스카우트 취향 적중 +6, 그 외 +2) + 고졸 나이 프리미엄(+10). 등급(S~D)과 스카우트 코멘트 표시
- FR-CMB-04 컴바인 결과 기반 드래프트 실행 (선수당 1회)
  - 등급별 라운드: S 1R / A 2~3R / B 4~8R / C 9~14R / D 15~20R (등급 안에서 점수가 높을수록 앞 라운드)
  - 라운드 내 순번(1~30)과 지명 팀은 랜덤
  - 계약금: 전체 1순위 $9,500,000에서 순번마다 4% 감소, 최저 $150,000
  - 시작 리그: 대졸 1~10R은 싱글A, 그 외(고졸 전원 포함)는 루키리그
  - 미지명은 M1에서 없음 (D등급도 15~20R 지명)

### 3.4 시즌 / 시리즈 진행 (SEASON)
- FR-SEA-01 정규시즌은 **54시리즈 × 3경기 = 162경기** (실제 MLB 편성과 동일). 마이너리그 레벨도 같은 편성을 사용
- FR-SEA-02 "다음 시리즈 진행" 클릭 시 서버에서 즉시 시뮬레이션 후 결과 반환. 진행 횟수 제한 없음
  - (M3-3 구현) `SeasonService.playNextSeries`: 일정·양 팀 전력 조회 → 선수 스냅샷으로 시리즈 계산 → `series_records` 저장 → 시즌 누적 기록·피로·등판 상태·부상 갱신 → 시리즈 연봉 적립 → 훈련 대기 상태
  - 시즌 진행 상태와 누적 기록은 `player_seasons` (선수·연도당 1행, 기록은 JSON, 낙관적 락으로 중복 진행 방지)
  - 부상 결장 중에도 시리즈는 진행 — 팀 경기만 치르고 내 선수 기록은 쌓이지 않음, 결장 시리즈 1 감소
  - 54번째 시리즈가 끝나면 시즌 종료(COMPLETED). 다음 시즌 전환은 M4
- FR-SEA-03 출전 여부 판정: 소속 레벨 기준 OVR로 판정 (팀 내 경쟁 있음)
  - 야수: 레벨 평균 OVR 이상이면 주전(매 경기 선발), 조금 낮으면 플래툰(일부 경기 선발·대타), 많이 낮으면 벤치(대타·대수비 위주). 피로도·부상도 반영
  - 타순은 포지션과 OVR·능력치 성향으로 자동 결정 (예: 주력·선구안 높으면 1번, 파워 높으면 3~4번), 유저 선택 없음
  - 선발투수(SP): 5인 로테이션, 5경기마다 1회 선발 (회복이 덜 됐으면 하루 밀림)
  - 마무리투수(CP): 경기마다 이닝별 점수를 시뮬레이션해 9회 등판 상황을 판정. 세이브 상황(1~3점 리드) 또는 9회 동점이면 등판. 단 연투 제한(3일 연속 금지, 전날 30구 이상이면 휴식)에 걸리면 등판 불가. 4일 이상 등판이 없으면 점검 등판
- FR-SEA-04 결과 표시
  - 시리즈 승패, 경기별 스코어
  - 내 선수 경기별 기록 (타자: 타석·안타·HR·타점·볼넷·삼진 / 투수: 이닝·피안타·실점·K·BB)
  - 하이라이트 텍스트 로그 ("7회말 역전 투런 홈런!")
- FR-SEA-05 시즌 누적 기록 및 세이버 지표 (AVG/OBP/SLG/OPS, ERA/WHIP/K9, 간이 WAR)
- FR-SEA-06 승격/강등 (M4-1): 9시리즈마다(9·18·27·36·45번째 시리즈 후) 판정, 한 번에 한 레벨 (루키 → A → AA → AAA → 메이저)
  - 판정 점수 = (OVR − 소속 레벨 평균) + 2 × 최근 9시리즈 성적 점수
  - 성적 점수: 타자 (OPS − .720) / .050, 선발 (4.30 − ERA) / 0.60, 마무리 (4.00 − ERA) / 0.80 — ±4 로 제한, 표본 부족(타자 40타석·선발 15이닝·마무리 5이닝 미만)이면 0
  - 승격: 점수 +4 이상 / 강등: 점수 −8 이하 (루키는 강등 없음, 메이저는 승격 없음) / 부상 결장 중에는 판정하지 않음
  - 레벨이 바뀌면 같은 일정의 상대가 새 레벨 산하팀으로 바뀌고, 연봉·상대 전력도 새 레벨 기준
  - 레벨 이동 이력 저장, 메이저리그에서 보낸 시리즈 수 누적 (서비스 연수 계산용, M4-6)
- FR-SEA-07 랜덤 이벤트: 슬럼프, 감독 면담, 트레이드 루머 등
- FR-SEA-09 부상 (판정은 M2 엔진, 결장 처리는 M3)
  - 출전한 경기마다 부상 확률 판정. 내구성이 높을수록, 피로도가 낮을수록 확률↓ (피로도 70 초과 시 크게 증가)
  - 심각도: 경미 1~3시리즈 / 중상 5~20시리즈 / 시즌 아웃 (확률은 경미 > 중상 > 시즌 아웃)
  - 결장 중에는 시리즈 결과에서 빠지고 기록이 쌓이지 않음. 훈련 +1은 정상 지급(재활 훈련)
  - 부상 이력은 저장해서 커리어 페이지에 표시
- FR-SEA-10 시즌 연도: 2025년 드래프트 컴바인·드래프트 → **2026시즌**부터 시작. 이후 시즌마다 +1년
- FR-SEA-08 (M4) 월간 시상 (4~9월, 9시리즈마다): 이달의 선수(타자/투수), 이달의 루키, 이달의 구원투수, 마이너리그 이달의 선수. 상 1개당 스탯업 기회 +1

### 3.5 훈련 (TRAINING)
- FR-TRN-01 시리즈가 끝날 때마다 훈련 1회: 내 선수 능력치 11개 중 1개를 골라 **확정 +1** (랜덤 없음, 100이면 선택 불가)
  - **훈련을 고르기 전에는 다음 시리즈를 진행할 수 없음** (M3)
  - 단, 추후 자동 진행 모드 도입 가능성을 위해 "훈련 선택"은 한 곳(서비스 메서드)으로 모아, 유저 선택 대신 자동 훈련 순서가 고를 수 있는 구조로 만든다
  - (M3-4 구현) `TrainingService`: 훈련 대기 상태에서만 가능, 시리즈당 1회, 포지션에 없거나 100인 능력치는 거절(기회 소모 없음). 모든 훈련은 `training_logs`에 시즌·시리즈·능력치·결과값·출처(MANUAL/AUTO)로 기록
  - 자동 선택 구조: `AutoTrainingOrder` — 순서 목록을 돌아가며 고르고 최대치는 건너뜀 (`trainAutomatically`, 화면 미연결)
- FR-TRN-02 시즌 54회 훈련만으로 OVR 약 +4.9 (54 ÷ 11)
- FR-TRN-03 시상으로 받은 스탯업 기회는 보유 포인트로 적립, 원하는 때에 능력치 +1로 사용 (이월 가능)
- FR-TRN-04 (보류) 빠른 진행용 "자동 훈련 순서" 설정 (예: 컨택 → 파워 → 선구안 순환) — 도입 여부는 추후 결정, 구조만 열어 둠
- FR-TRN-05 훈련은 피로도와 무관. 부상 결장 중에도 훈련 기회는 정상 지급

### 3.6 시즌 종료 / 커리어 (CAREER)
- FR-CAR-01 시즌 시상: MVP·사이영상(5), 월드시리즈 MVP(4), 신인왕(3), 리그 챔피언십시리즈 MVP·실버슬러거·골드글러브·올해의 구원투수·재기상·마이너리그 올해의 선수(2), 올스타·올스타전 MVP·마이너 레벨 올스타(1). 괄호는 스탯업 기회 수. 리그 내 가상 선수 대비 성적으로 판정
- FR-CAR-02 계약/연봉: MLB 제도를 단순화 (상세: [league-world.md](league-world.md) 7~8장)
  - 계약금(드래프트) → 마이너 연봉 → 메이저 최저 연봉(서비스 0~2년) → 연봉조정(3~5년) → FA(6년 이후)
  - 마이너리그 기간은 서비스 연수에 포함하지 않음
  - (M3) 시리즈마다 소속 레벨 연봉을 일할 적립
  - (M4-6 구현) 연봉조정 협상·청문회, 연장 계약 제안 이벤트, FA 협상(구단 예산 여유 안에서 오퍼, 무리한 요구 시 구단 이탈). 상세: [league-world.md](league-world.md) 8.2.1
- FR-CAR-08 수령 원장: 계약금·연봉·수상 보너스를 모두 원장에 기록 → 커리어 누적 연봉 (M3부터 적립, 랭킹은 M5)
- FR-CAR-09 구단 페이롤 (M3 생성·표시, M4 변동): NPC 연봉·계약 연수, 구단 예산(재정 규모 × 구단주 투자 성향), 페이롤, 사치세 기준선 — FA 입찰력·트레이드 성향·팀 전력과 연결
- FR-CAR-06 FA 이적 시장 (M4)
  - 오프시즌에 내 선수 가치(OVR, 나이, 최근 2시즌 성적)로 여러 구단이 오퍼 생성 (계약 연수, 연봉, 팀 전력 표시)
  - 유저가 오퍼 하나를 골라 이적하거나 원소속팀 잔류
  - 이적 시장 전체(NPC 선수 이동)는 시뮬레이션하지 않음 — NPC 선수는 기록 비교·시상 경쟁용으로만 존재
- FR-CAR-07 트레이드 이벤트 (M4)
  - 협상형 트레이드(선수 맞교환)는 하지 않음
  - 시즌 중 랜덤 이벤트: 트레이드 루머 → 트레이드 성사로 내 선수가 다른 팀으로 이적. 소속팀이 리빌딩 중이거나 내 선수 가치가 높을수록 확률↑ (트레이드 마감 7월 말까지)
  - 유저의 "트레이드 요청": 일정 확률로 성사, 실패 시 감독 신뢰도 하락
  - 이적하면 팀 전력이 바뀌어 출전 기회·세이브 기회·포스트시즌 가능성이 달라짐
  - (M4-7 구현) `TradeRules` / `TradeService`
    - 기간: 6~36번째 시리즈 뒤, 메이저·트리플A 소속, 부상 결장 중 제외
    - 시리즈당 확률 1.2% × (소속팀 승률 .450 미만 ×2) × (OVR 70+ ×1.5) × (연봉 $15M+ & 예산 초과 ×2) × (요청 거절 이력 ×4), 최대 30%
    - 처음 걸리면 루머, 루머 상태에서 또 걸리면 트레이드 성사. 행선지는 승률 .520+ 경쟁 팀 중 (승률 − .5 + 예산 여유) 가중
    - 트레이드 요청: 시즌당 1회, 마감 전 — 30% 성사 / 실패 시 거절 이력(이후 확률 ×4)
    - 계약·레벨 유지, 다음 시리즈부터 새 구단 일정. 시리즈 결과 화면 배너, 시즌 허브 "트레이드 소식"
    - 단순화: 트레이드 전 메이저 시리즈의 팀 결과도 순위표에서는 새 구단 기록으로 반영됨
- FR-CAR-03 나이 증가 및 노화: 32세부터 시즌 종료 시 신체 능력치 고정 하락 (나이 구간별 표, 랜덤 없음)
  - (M4-5 구현) 정규시즌·포스트시즌 종료 후 "다음 시즌 시작" → 리그 월드 변화(NPC 성장·은퇴·FA·콜업·예산·팜) + 내 선수 나이·노화 + 45세 강제 은퇴 → 다음 시즌 1번 시리즈. 상세: [league-world.md](league-world.md) 4.1
- FR-CAR-04 은퇴 (M4-7): 자발적 은퇴(유저가 선택) + **45세가 되면 강제 은퇴** (능력치 기준 강제 은퇴는 없음)
  - (구현) 커리어 화면에서 확인란에 '은퇴'를 입력해야 진행. 은퇴하면 슬롯 반납, 시리즈 진행 불가, 대시보드 "은퇴 선수"에서 커리어 열람
  - 커리어 화면: 시즌별 기록(전 레벨), 메이저 통산, 수상, 승격·강등·트레이드 이력, 커리어 수령액, 명예의 전당 점수
    - 타자 = 메이저 안타/20 + 홈런/5 + 수상 포인트 × 3 + 메이저 주요 시즌(27시리즈 이상) × 2
    - 투수 = 메이저 승 × 2 + 세이브/2 + 탈삼진/30 + 수상 포인트 × 3 + 메이저 주요 시즌 × 2
    - 150 이상 "명예의 전당 헌액", 100 이상 "후보"
- FR-CAR-05 커리어 요약 페이지: 연도별 기록표, 수상 내역, 명예의 전당 점수

### 3.8 리그 / 가상 데이터 (LEAGUE)
- FR-LEA-01 실제 MLB 30팀 명칭·리그·디비전 구성 사용 (AL/NL 각 3개 디비전). 마이너리그 산하팀은 실명 대신 "메이저 구단명 + 레벨"로 표시 (예: 디트로이트 타이거스 루키 / A / AA / AAA)
  - 로고·엠블럼 이미지는 사용하지 않고 팀명 텍스트 + 팀 컬러만 표시
  - 팀 데이터는 Flyway 시드 데이터(teams 테이블)로 관리해, 추후 공개 서비스 전환 시 가상 명칭으로 교체 가능하도록 함
  - ⚠️ 실제 MLB 명칭은 상표권 대상이므로 학습·개인 프로젝트 범위에서 사용. 공개·상업 서비스 전환 시 재검토 필요
- FR-LEA-02 리그 월드 (상세: [league-world.md](league-world.md))
  - 내 선수 커리어마다 별도 월드. 구단당 1군 26명만 개별 NPC 선수로 생성, 마이너리그는 구단 팜 점수로 추상화
  - 팀 전력은 1군 선수 능력치로 계산 (강제 평균 회귀 없음 → 만년 강팀·탱킹 가능)
  - 구단 성향: 재정 규모(빅/중간/스몰마켓, FA 영입력), 팜 점수(콜업 유망주 수준)
  - 시즌 전환 시 NPC 성장·노화·은퇴·FA·콜업·강등 (M4)
  - NPC 신인은 매 시즌 컴바인 없이 드래프트만 (M4)
  - NPC 시즌 기록은 능력치 기대치 + 랜덤으로 통계 생성 (시상·리더보드용, M4)
- FR-LEA-03 팀 순위표(팀 전력 기반 기대 승률 + 랜덤, 내 팀은 실제 결과), 포스트시즌 (M4)
  - 실제 MLB 방식: 리그당 6팀(지구 우승 3 + 와일드카드 3), 총 12팀
  - 와일드카드 시리즈(3전 2선승, 지구 우승 상위 2팀은 부전승) → 디비전시리즈(5전 3선승) → 챔피언십시리즈(7전 4선승) → 월드시리즈(7전 4선승)
  - (M4-4 구현) 정규시즌 54시리즈 + 마지막 훈련 후 시작. 시드는 54시리즈 종료 시점 순위표 (`postseasons` 테이블, 대진은 JSON)
    - 홈 배정: 3전제 상위 시드 전부 / 5전제 2-2-1 / 7전제 2-3-2
    - 라운드마다 "진행" 1회 — 내 구단 시리즈는 내 선수가 메이저 소속(부상 아님)이면 경기 단위로 직접 뜀(1경기 시리즈 입력을 반복, 피로·등판 상태 유지), 나머지는 팀 전력 + 홈 +2 로 진행
    - 내 구단이 진출 실패·탈락하면 남은 라운드를 한 번에 진행해 우승팀까지 표시
    - 시리즈 MVP (팀이 이긴 경우): 타자 12타석 이상 OPS .900 이상 / 선발 10이닝 이상 ERA 2.50 이하 / 마무리 2세이브 이상 무실점 → 챔피언십 MVP(+2), 월드시리즈 MVP(+4)
    - 포스트시즌 기록은 정규시즌과 별도, 훈련·연봉 적립 없음
- M4 진행 순서: M4-1 승격·강등 → M4-2 NPC 기록·순위표 → M4-3 시상·스탯업 포인트 → M4-4 포스트시즌 → M4-5 시즌 전환 → M4-6 계약·협상 → M4-7 트레이드·은퇴

## 4. 시뮬레이션 엔진 설계 원칙
- 모든 시뮬레이션·랜덤은 **서버에서만** 수행 (클라이언트 조작 방지)
- 타석(투구) 단위 확률 모델: 타자 능력치 vs 상대 투수 능력치 → 결과 확률(삼진/볼넷/안타/2루타/3루타/홈런/아웃) 산출
- 경기 단위 팀 득실은 팀 전력 + 내 선수 기여도로 간이 계산
- 시리즈마다 시드(seed)를 저장해 결과 재현/디버깅 가능하도록 함
- **저장 원칙: DB + 시드 재현** (파일시스템 저장은 사용하지 않음)
  - DB에 저장: 확정값(능력치, 계약, 수상, 부상 이력), 시리즈별 요약(승패, 내 선수 기록), 시즌 누적 기록
  - 저장하지 않음: 타석별 상세 로그·하이라이트 문구 → 시리즈의 시드 + 당시 입력값(능력치 스냅샷, 상대 정보)으로 볼 때 다시 계산
  - 같은 시드·같은 입력이면 항상 같은 결과가 나와야 함 (엔진 내부 랜덤은 시드 기반 하나만 사용)
  - NPC 선수 기록은 시즌별 요약(순위표, 시상 후보)만 저장
- 밸런스 계수는 설정 파일(application.yml 또는 DB 테이블)로 분리해 조정 용이하게
- **기준 기록 보정:** 메이저리그 평균(OVR 65) 선수가 평균 상대를 만나면 실제 MLB 리그 평균 기록이 나오도록 확률을 맞춘다 (타자: 타율·출루율·장타율·K%·BB%·HR 비율, 투수: ERA·K/9·BB/9·HR/9). 검증은 수천 시즌 반복 시뮬레이션 테스트로 한다

### 7.1 재화 시스템 확장 설계 (MVP 미구현)
MVP는 "훈련 선택만으로 성장" 원칙을 지키되, 추후 아래 용도의 재화를 붙일 수 있게 구조만 열어 둔다.
- 예상 용도: **드래프트 확정픽**(지명 라운드 보장), **시작 능력치 포인트 구매**(선수 생성 시 추가 포인트)
- 재화는 선수가 아닌 **계정 단위** 보유 (새 선수 생성 시 사용하는 용도이기 때문)
- 획득 경로 후보: 은퇴 선수의 커리어 점수 비례 지급, 시상·업적 보상
- 구조
  - `wallet` 패키지 + `CurrencyService` 인터페이스 (지급/차감은 반드시 이 서비스를 통해서만)
  - 테이블: `user_wallets(user_id, balance, version)`, `currency_transactions(id, user_id, amount, reason, ref_id, created_at)` — 잔액 변경 이력을 원장(ledger)으로 남김
  - 선수 생성·드래프트 로직에 "보너스 적용" 확장 지점(예: `CreationBonus`, `DraftGuarantee`)을 두되 MVP에서는 항상 비어 있음
- 테이블 생성은 재화 기능을 도입하는 마일스톤에서 Flyway로 추가 (MVP 스키마에는 넣지 않음)
