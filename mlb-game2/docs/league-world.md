# 리그 월드 설계 (v0.1)

> 팀 전력과 NPC 선수를 어떻게 다룰지에 대한 설계. 결정일 2026-10-15.

## 1. 원칙
- **팀 전력은 직접 변동시키지 않는다.** 강제 평균 회귀 없이, 1군 선수들의 능력치로부터 계산된다
- 만년 강팀·만년 탱킹·신데렐라 시즌이 세이브마다 자유롭게 나오도록, 변화의 원인은 선수(성장·노화·이적·운)와 구단 성향에 둔다
- 개별 데이터화는 **메이저리그 1군에 한정**하고, 마이너리그는 구단의 팜 점수로 추상화한다
- 리그 월드는 **내 선수 커리어마다 따로** 존재한다 (유저마다 시즌 진행 속도가 다르므로 공유 불가)

## 2. 구성
| 요소 | 내용 |
|---|---|
| 구단 | 실제 MLB 30개 구단 (V2 시드) |
| 1군 로스터 | 구단당 26명 — 타자 13 (주전 9 + 벤치 4), 투수 13 (선발 5 + 불펜 8). 리그 전체 약 780명 |
| NPC 선수 | 가상 이름, 포지션, 투타, 나이, 능력치 11개, 숨김 잠재력. 내 선수와 같은 능력치 체계 |
| 구단 성향 (잘 바뀌지 않음) | **재정 규모** (빅마켓/중간/스몰마켓) — FA 영입력 / **팜 점수** — 콜업 유망주 수준 |
| 마이너리그 | 개별 선수 없음. 구단 팜 점수로만 존재. 내 선수의 마이너 소속 표시는 "구단명 + 레벨" |

## 3. 팀 전력 계산 (M3-2, `TeamStrength`)
- 타선 = 주전 9명 평균 OVR / 선발진 = 선발 5명 평균 / 불펜 = 불펜 7명 + 마무리 평균 (벤치는 미반영)
- 경기 엔진(`TeamRatings`)에 세 부문을 따로 넣는다: 타선 → 상대 타자 능력치, 1~6회 투수 → 선발진, 7회 이후 → 불펜
- 마이너리그 = 레벨 평균 + (팜 점수 − 60)/10 (팜 90 → +3, 30 → −3), 세 부문 동일
- 종합 전력(표시·기대 승률용) = 타선 50% + 선발 30% + 불펜 20%
- 내 선수는 로스터 26명과 별도로 존재 (M3 에서는 내 팀 전력 계산에 넣지 않음 — 내 선수는 경기에서 직접 뛴다)

## 3.1 시즌 일정 (M3-2, `ScheduleGenerator`)
- 54시리즈: 같은 지구 4팀 × 4 + 같은 리그 다른 지구 10팀 × 2 + 인터리그 15팀 × 1 + 인터리그 3팀 추가 1
- 홈 27 / 원정 27, 같은 상대 연속 시리즈 없음, 9시리즈마다 한 달(4~9월)
- 저장하지 않음: 시드 = 월드 시드 × 31 + 연도 × 1,000,003 + 구단 id → 언제든 같은 일정
- 마이너리그도 같은 구조. 상대는 각 구단의 같은 레벨 산하팀("디트로이트 타이거스 AA")

## 4. 시즌이 바뀔 때 (M4)
1. NPC 성장·노화: 나이·잠재력 기반 + 랜덤 편차 (급성장·부진 가능)
2. 은퇴: 나이·능력치 기준
3. FA: 계약 만료 선수가 재정 규모에 따라 다른 구단으로 이동 (빅마켓일수록 유리)
4. 콜업: 1군 빈자리를 팜 점수 + 랜덤으로 생성한 유망주로 채움 → 이때부터 개별 선수
5. 강등: 1군에서 밀려난 선수는 "마이너" 상태로 남음 (경기 시뮬레이션 없음, 성장·노화는 계속, 재콜업 가능)
6. 신인 드래프트: **NPC 신인은 컴바인 없이 드래프트만**. 전 시즌 하위 팀이 앞 순번 → 구단 팜 점수에 반영

시즌 중에도 부상·부진으로 1군 빈자리가 생기면 같은 방식으로 콜업한다. (시즌 중 콜업은 미구현 — 현재는 시즌 전환 때만)

### 4.1 구현 (M4-5, `WorldEvolution` + `SeasonTransitionService`)
- 조건: 정규시즌 54시리즈 + 마지막 훈련 + 포스트시즌 종료 → 시즌 허브의 "다음 시즌 시작"
- NPC 성장·노화 (능력치마다): 기본 = 24세 이하 +2 / 25~27세 +1 / 28~30세 0 / 31~33세 −1 / 34~36세 −2 / 37세~ −3, 정규분포 ± 1.2
  - 잠재력에 도달한 선수는 성장분 0, 27세 이하 급성장 4% (+3), 전 연령 급락 4% (−3)
- NPC 은퇴: 40세 이상 / 지난해 미계약 FA 34세 이상 / 36세 이상은 25% + 기량 하락 보정 / 30세 넘고 OVR 48 미만은 50%
- 계약: 1년 경과(메이저 소속이면 서비스 +1) → 만료 시 서비스 6년 미만은 재계약(최저·연봉조정 금액), 6년 이상은 FA
- 구단 예산 = 기본 예산 × 투자 성향 × (1 + (승률 − .500) × 0.4), 페이롤이 사치세 기준선($240M) 초과면 × 0.95
- 팜 점수(신인 드래프트 반영) = 팜 × 0.85 + 9 + 드래프트 보너스(꼴찌 +6 ~ 1위 0) ± 3
- FA 시장: OVR 높은 순으로, 예산 여유 ≥ 요구 연봉이고 같은 역할군 최약체보다 2 이상 나은 경우 입찰. 요구 연봉 = 시장가 × (0.9~1.2) × (빅 1.1 / 중간 1.0 / 스몰 0.9), 빅마켓 입찰 가중 1.3. 계약 연수 29세 이하 3~5년 / 30~33세 2~3년 / 34세~ 1년
- 로스터 재편: 포수·유격수 먼저 → OVR 순 주전 9·벤치 4, 선발 5(선발 포지션), 마무리 1(마무리 우선), 불펜 7. 넘치면 마이너로, 모자라면 콜업
- 콜업 유망주: OVR = 56 + (팜 − 60)/6 ± 4, 21~24세, 잠재력 = OVR + 5~17, 최저 연봉, 서비스 0년
- 내 선수: 나이 +1 → 노화(player-attributes.md 6장) → 45세면 강제 은퇴(슬롯 반납). 소속 레벨·구단은 유지하고 새 시즌은 1번 시리즈부터
- 결과 요약(노화, 은퇴·FA·콜업 수, 대형 FA 계약 3건)을 시즌 허브 "오프시즌 소식"으로 표시

## 5.1 구현 (M4-2)
- `NpcStatGenerator`: 월(27경기) 단위로 생성, 저장하지 않음 — 시드 = 월드 시드·연도·월·선수 id
  - 타자: 출전율 주전 93% / 벤치 45%, 경기당 타석 주전 4.2 / 벤치 1.6, 타석마다 M2 타석 모델(상대 평균 65, 우완 72%)
  - 득점·타점 = Base Runs 추정 × (0.8~1.15 운), 도루는 1루 출루마다 도루 능력치로 시도·성공
  - 수비: 경기당 타구 4.5, 수비·송구 능력치로 막은 안타·실책·보살
  - 선발: 월 5~6선발(1·2선발이 더 자주), 투구 수 한도 = 60 + 체력/2, 타자당 3.85구 × 투구 효율 보정, 실점 = 상대 기록 Base Runs. 승패는 72% 선발에 붙고 팀 승률 + 실점으로 결정
  - 불펜·마무리: 경기의 40% / 42% 등판, 1이닝. 마무리는 세이브 상황 62% × 팀 승률 보정
- `StandingsGenerator`: 시리즈 차수마다 30팀을 15쌍으로 짝지어 3경기, 경기 승률 = 1 / (1 + e^(−0.06 × 전력 차)). 리그 전체 승 = 패. 저장 없음
  - 내 선수가 메이저에서 뛴 시리즈는 내 팀의 실제 결과로 바꾸고, 짝지어진 상대에게 반대 결과
- `StandingsTable`: 지구 순위·승차, 포스트시즌 시드(지구 우승 3 → 1~3번, 와일드카드 3 → 4~6번)
- 리더보드: 타율·홈런·타점·OPS·도루 / 평균자책점·승·탈삼진·세이브 상위 5명. 비율 기록은 규정 타석(팀 경기 × 3.1)·규정 이닝(× 1.0). 지난 달까지 기준, 내 선수는 메이저에서 뛴 기록으로 포함
- 화면: `/game/players/{id}/league`

## 5. NPC 시즌 기록 = 통계 생성 (M4)
- 30개 구단 경기를 타석 단위로 모두 돌리지 않는다
- 선수 능력치 → M2 타석 모델의 기대 비율(리그 평균 상대) → 역할별 출전 수(주전 타석, 선발 이닝 등) × 기대 비율 + 랜덤 편차 = 시즌 기록
- 용도: 월간·시즌 시상 경쟁, 리그 리더보드, 다른 선수 비교
- 팀 순위: 팀 전력으로 기대 승률을 구하고 랜덤 편차를 더해 162경기 성적 생성 (내 팀은 실제 시리즈 결과 반영)

## 6. 저장 (DB + 시드 재현 원칙)
- 월드 시드: 커리어 시작 시 생성, 초기 로스터·이름 생성에 사용
- 저장: 현재 시즌 NPC 선수(능력치·나이·소속·상태), 구단 성향, 시즌별 요약(순위, 시상, 리더보드 상위)
- 규모: 커리어당 NPC 약 800~1,000명 × 1행 + 시즌 요약 — 커리어당 수백 KB 수준

## 7. 페이롤 (구단 재정)
> 정확한 회계가 아니라, 팀 전력·이적 시장 행보에 "이유"가 생기도록 서로 연결하는 근사 지표

### 7.1 선수 연봉 (NPC + 내 선수 공통 규칙)
| 구간 | 연봉 |
|---|---|
| 메이저 서비스 0~2년 | 최저 연봉 $760,000 |
| 서비스 3~5년 (연봉조정) | 시장가 × 40% / 60% / 80% (3·4·5년 차), 성적 반영 |
| FA 계약 | 계약 당시 시장가 × 연수 (남은 계약 연수가 0 이 되면 FA) |

- 시장가(OVR 기준) = $8M × e^(0.075 × (OVR − 65)) → OVR 45 ≈ $1.8M / 55 ≈ $3.8M / 65 = $8M / 75 ≈ $17M / 85 ≈ $36M (최저 연봉 미만이면 최저 연봉)

### 7.2 구단 예산
| 항목 | 내용 |
|---|---|
| 기본 예산 | 빅마켓 $230M / 중간 $160M / 스몰마켓 $100M |
| 구단주 투자 성향 | 0.85 ~ 1.15 배 (잘 바뀌지 않음) |
| 예산 변동 (M4) | 최근 성적이 좋으면 수입 증가 → 예산↑, 장기 부진 → 예산↓ |
| 사치세 기준선 (M4) | $240M. 넘으면 다음 시즌 예산 부담 |
| 페이롤 | 1군 26명 연봉 합계 (내 선수가 1군이면 포함) |

### 7.3 상관관계
| 연결 | 동작 (M4) |
|---|---|
| 페이롤 ↔ 팀 전력 | 돈을 쓴 만큼 좋은 선수가 모인다. 저연봉 유망주가 터지면 적은 돈으로도 강팀 가능 |
| 예산 여유 ↔ FA | 예산이 남는 구단만 FA 입찰, 빅마켓은 더 높게 부른다 |
| 예산 초과 ↔ 트레이드 | 초과 구단은 고연봉 선수를 내보내고, 리빌딩 구단은 베테랑을 판다 |
| 내 선수 | FA 오퍼 금액은 구단 예산 여유 안에서 생성. 내 연봉이 커지면 예산 초과 구단의 트레이드 대상이 될 수 있음 |

## 8. 내 선수 연봉·협상
### 8.1 연봉 단계
| 단계 | 시점 | 연봉 |
|---|---|---|
| 계약금 | 드래프트 (M1) | 지명 순번별 금액 |
| 마이너리그 | 콜업 전 | 루키 $20K / A $25K / AA $30K / AAA $40K (시즌 기준, 시리즈마다 일할 적립) |
| 최저 연봉 | 메이저 서비스 0~2년 | $760,000 (메이저에 있던 시리즈만큼 일할 적립) |
| 연봉조정 | 서비스 3~5년 | **협상** (M4) |
| FA | 서비스 6년 이후 | **여러 구단과 협상** (M4) |

- 서비스 연수: 메이저리그에서 보낸 시즌(시리즈 수 기준)만 센다

### 8.2 협상 (M4)
- **연봉조정**: 구단 제시액 → 수락 / 요구액 제시. 불합의 시 청문회 — 성적 기반 적정 연봉에 더 가까운 쪽 금액으로 결정 (무리한 요구는 구단 제시액 채택 위험)
- **연장 계약 제안** (랜덤 이벤트): FA 전 다년 계약 제안 — 수락하면 안정, 거절하면 FA 대박 또는 부진·부상 위험
- **FA**: 여러 구단 오퍼(연수·연봉·팀 전력). 더 높게 부르면 시장가 대비 초과분만큼 구단 이탈 확률↑. 원소속팀 잔류 포함

### 8.2.1 구현 (M4-6, `ContractRules` + `ContractService`)
- 서비스 연수: 메이저 시리즈 46개 = 1년 (마이너 제외)
- 평가 OVR = OVR + min(4, 지난 시즌 수상 포인트 / 2)
- 시즌 중: 메이저에 처음 올라오면 최저 연봉($760K) 1년 계약. 시리즈마다 연봉 1/54 적립 — 보장 계약(연봉조정·연장·FA)은 마이너로 내려가도 계약 연봉, 그 외는 레벨 연봉
- 오프시즌(시즌 전환 때): 다년 계약은 1년 차감 / 만료 시
  - 서비스 0~2년: 최저 연봉 재계약
  - 서비스 3~5년: 연봉조정 — 적정 = 시장가(평가 OVR) × 40/60/80%, 구단 제시 = 적정 × 90%. 수락 또는 청문회(요구액 ≥ 제시액, 적정에 더 가까운 쪽 채택, 같으면 구단). 거절 불가
  - 서비스 6년+: FA — 예산 여유가 있는 구단 최대 4곳(원소속팀은 여유 80%만 있어도 우선) 오퍼. 연봉 = 시장가 × (0.85~1.2) × 재정 규모, 연수 29세 이하 3~5 / 30~33세 2~3 / 34세+ 1
  - 연장 계약 제안: 서비스 2~5년 & 평가 OVR 68 이상이면 35% — 연봉 = 시장가 × 75%, 연수 = FA까지 남은 기간 + 2 (3~6년)
- 협상: 수락 / 청문회 / FA 역제안(초과율 x 에 수락 확률 1 − 3x, 결렬 시 그 구단 철수) / 거절. FA 오퍼가 모두 사라지면 원소속팀이 1년·시장가 60% 제안 (FA 미아 방지)
- 하나를 체결하면 같은 오프시즌의 다른 제안은 소멸. FA 이적은 시즌 1번 시리즈 전이면 새 시즌 소속도 변경
- 결정하지 않은 제안이 있으면 시리즈 진행 불가 (시즌 허브에 안내), 화면: `/game/players/{id}/contract`

### 8.3 수령 원장 (누적 연봉 랭킹용)
- `player_earnings(player_id, season_year, type, amount, created_at)` — type: SIGNING_BONUS / SALARY / AWARD_BONUS
- 누적 연봉 수령액 = 원장 합계 → M5 랭킹 카테고리 "커리어 누적 연봉"
- 재화(M6)와는 별개 — 랭킹 왜곡 방지

## 9. 초기 월드 생성 규칙 (M3-1, `WorldGenerator`)
- 시점: 내 선수 드래프트 직후, 시드 하나로 2026시즌 월드 생성 (같은 시드 → 같은 월드)
- 재정 규모: 빅마켓 NYY·LAD·NYM·BOS·PHI·CHC·SF·LAA / 스몰마켓 TB·ATH·MIA·PIT·KC·CLE·MIL·CIN / 나머지 중간
- 구단주 투자 성향 85~115%, 팜 점수 30~90 (재정과 무관 — 스몰마켓 명문 팜 가능)
- 팀 목표 전력 = 65 + 재정 보정(빅 +2 / 스몰 −2) + (투자 성향 − 100)/10 + 정규분포 × 2.5
- 역할 보정: 주전 +1.5 / 벤치 −6 / 선발 1~5선발 +6·+3·+1·−2·−4 / 불펜 −3 / 마무리 +2, 선수마다 정규분포 × 4 (OVR 35~92)
- 능력치: OVR 주변 ±7 로 흩뿌린 뒤 평균을 OVR 에 맞춤 (20~99)
- 나이 22~37 (29~30세 최빈), 잠재력 = OVR + (25세 이하 3~15 / 26~28세 0~5 / 그 이상 0)
- 투타: 투수 좌완 28%, 포수·2루·3루·유격은 우투, 1루·외야 좌투 20%, 타석 우 60% / 좌 32% / 스위치 8%
- 서비스 연수 = 나이 − 23 − (0~2), 연봉은 7.1 규칙 (FA 선수는 시장가 × 0.8~1.2, 남은 계약 1~5년)
- 이름: 미국 62% / 중남미 28% / 일본 4% / 한국 3% / 대만 3% 가상 이름
- 저장: `league_worlds` 1행, `world_teams` 30행, `npc_players` 780행 (능력치는 "65,70,..." 한 칸, 배치 삽입)
