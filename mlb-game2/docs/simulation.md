# 시뮬레이션 엔진 설계 (M2)

> 코드: `com.mlbgame.simulation`. 보정 수치: `application.yml` 의 `game.simulation.*`

## 1. 타석 결과 모델 (2단계 완료)

### 1.1 방식: 로그 오즈 가산
```
logit(p) = logit(MLB 평균 확률) + Σ 계수 × g((능력치 − 65) / 10)

g(d) = d                                  (d ≤ 0, 기준 이하)
g(d) = 2.07 × (1 − e^(−d / 2.75))         (d > 0, 기준 이상은 포화 곡선)
```
- 능력치 65(메이저리그 평균)끼리 만나면 MLB 리그 평균이 그대로 나온다
- 능력치 10 차이 = 로그 오즈 `계수`만큼 이동. 확률이 0~1을 벗어나지 않고, 극단으로 갈수록 효과가 완만해진다
- **기준 이상 압축 (M5-3):** 직선 그대로면 OVR 85 타자가 타율 .367·OPS 1.16, OVR 80 선발이 ERA 1.8 로 폭주했다.
  포화 곡선으로 +10 → 0.63, +20 → 1.07, +30 → 1.39 만 반영해 OVR 75 ≈ OPS .820 / 85 ≈ .920 / 95 ≈ 1.000 을 목표로 한다.
  기준 이하(마이너 레벨 대결 포함)는 직선 그대로라 레벨별 평균 기록 보정은 영향이 없다

### 1.2 계산 순서
1. 타석 기준으로 **삼진 / 볼넷 / 몸에 맞는 공 / 홈런** 비율 계산 (합계 최대 85%로 제한)
2. 나머지 = 인플레이 타구 → **BABIP**로 안타/아웃 분리
3. 인플레이 안타 → 2루타·3루타 비율로 분리, 나머지는 단타
4. 인플레이 아웃 → 땅볼 비율로 땅볼/뜬공 분리 (땅볼은 경기 진행 단계에서 병살 판정에 사용)

### 1.3 MLB 평균 기준값 (2023~2024 근사)
| 항목 | 값 | 결과 (65 vs 65) |
|---|---|---|
| 삼진 / 타석 | 22.5% | 타율 ≈ .246 |
| 볼넷 / 타석 | 8.5% | 출루율 ≈ .318 |
| 사구 / 타석 | 1.1% | 장타율 ≈ .406 |
| 홈런 / 타석 | 3.1% | 600타석 ≈ 19홈런 |
| BABIP | .295 | |
| 인플레이 안타 중 2루타 / 3루타 | 23% / 2% | |
| 인플레이 아웃 중 땅볼 | 45% | |

### 1.4 능력치 → 사건 연결 (계수는 능력치 10당 로그 오즈)
**균형 규칙:** 사건마다 타자 쪽 계수 합 = 투수 쪽 계수 합 → 타자·투수 능력치가 같으면 어느 레벨에서든 리그 평균 기록 (3루타만 예외)

| 사건 | 타자 (↑ 유리) | 투수 (↑ 유리) |
|---|---|---|
| 삼진 | 삼진 회피 −0.30 | 결정구 +0.20, 구속 +0.10 |
| 볼넷 | 선구안 +0.25 | 제구 −0.25 |
| 홈런 | 파워 +0.35 | 무브먼트 −0.28, 구속 −0.07 |
| BABIP | 컨택 +0.12, 주력 +0.04 | 구속 −0.10, 무브먼트 −0.06 |
| 2루타 비율 | 갭 파워 +0.20 | 땅볼 유도 −0.20 |
| 3루타 비율 | 주력 +0.35 | – |
| 땅볼 비율 | 파워 −0.15 | 땅볼 유도 +0.15 |

**상황 보정 (타자 유리 방향 edge 를 삼진 −, 볼넷 +½, 홈런 +, BABIP + 에 반영)**
- 좌우 상성: 같은 손 대결 −0.05 / 반대손 +0.10 × (1 − (투수 좌우 대응 − 65)/50). 스위치 타자는 항상 반대손
  - MLB 투수의 약 72%가 우완이라, 우타자의 평균 보정이 거의 0 이 되도록 같은 손 페널티를 절반으로 잡음
- 득점권: 0.08 × (타자 클러치 − 투수 위기 관리)/10
- 컨디션·피로: `PaContext` 의 능력치 오프셋으로 반영 (예: 피로 70 초과 → −5)

### 1.5 예상 기록 (메이저리그 평균 투수 상대, 모든 능력치 동일 가정)
| 타자 능력치 | 타율 | 삼진율 | 홈런/타석 |
|---|---|---|---|
| 40 | ≈ .150 | 35% | 1.3% |
| 65 | ≈ .246 | 22.5% | 3.1% |
| 85 | ≈ .345 | 15% | 6.1% |

실제 커리어에서는 소속 레벨의 상대(루키 35 ~ 메이저 65)를 만나므로, 능력치 40 선수도 루키리그에서는 평균 수준 기록이 나온다.

### 1.6 시드 재현
- 결과 추출은 `PaProbabilities.draw(RandomGenerator)` 하나로만 한다
- 시리즈마다 `SplittableRandom(seed)` 를 만들어 엔진 전체가 그 난수열만 쓴다 → 같은 시드·같은 입력이면 같은 결과

## 2. 경기 진행 (3단계 완료)

> 코드: `com.mlbgame.simulation.game.GameSimulator`. 입력 `GameSetup`, 결과 `GameResult`

### 2.1 구조
- 9이닝을 초·말로 나눠 **양 팀 모든 타석**을 1장의 타석 모델로 진행 (경기당 약 75타석)
- 내 선수를 뺀 나머지는 **팀 평균 능력치의 가상 선수** (내 팀 = 레벨 평균 ± 팀 전력, 상대 팀도 동일). 타순 9명 중 3명은 좌타
- 상대 선발은 28% 확률로 좌완, 7회부터는 불펜(좌우 교대)
- 9회 이후 홈 팀이 앞서면 말 공격 생략, 끝내기 시 즉시 종료. 연장은 승부치기(직전 타자가 2루 주자)

### 2.2 주루 (MLB 평균 근사, 내 선수가 주자면 주력으로 보정)
| 상황 | 확률 |
|---|---|
| 단타 때 2루 주자 홈인 | 60% |
| 단타 때 1루 주자 3루까지 | 28% |
| 2루타 때 1루 주자 홈인 | 40% |
| 땅볼 + 1루 주자 + 2아웃 미만 → 병살 | 30% (타자 주력 보정) |
| 땅볼 때 3루 주자 득점 / 2루 주자 3루 진루 | 50% / 50% |
| 뜬공 때 3루 주자 희생플라이 | 55% |

### 2.3 내 선수 — 타자
- 선발: 정해진 타순에서 모든 타석 / 대타: 7회 이후 9번 타순에 1타석 / 결장: 출전 없음
- 도루: 1루에 있고 2루가 비었을 때 시도 6%·성공 74% 기준, 도루 능력치로 보정
- 수비: 인플레이 타구가 내 위치로 올 확률(유격 16%, 2루 15%, 3루 12%, 외야 12%, 1루 10%, 포수 3%)
  - 수비 능력치가 높으면 안타 → 아웃 (최대 능력치 10당 6%), 낮으면 아웃 → 안타
  - 실책 1.5% 기준, 수비로 보정
  - 외야수: 단타 때 홈으로 달리는 주자를 송구로 잡는 보살 (송구 보정)
  - 포수: 상대 도루 시도(1루 주자, 2루 빔) 4%, 성공 75% 기준 → 송구로 저지율 보정
- 수비 기록은 "막은 실점" 추정치로 합산 (막은 안타 0.75, 실책 −0.75, 보살·도루 저지 0.5)

### 2.4 내 선수 — 선발투수(SP)
- 투구 수 한도 = 60 + 체력/2 (체력 65 → 92구, 85 → 102구). 한도 15구 전부터 구위 −4
- 강판: 한도 도달 또는 6실점 (타석이 끝날 때 판정), 이후 팀 평균 불펜
- 타석당 투구 수: 삼진 4.8 / 볼넷 5.6 / 사구 3.2 / 인플레이 3.3 × (1 − 0.04 × 투구 효율 차이/10) ± 1
- 승: 5이닝 이상 + 리드 상태로 강판 + 팀 승리 / 패: 뒤진 상태로 강판 + 팀 패배 / QS: 6이닝 이상 3실점 이하
- 단순화: 자책점 = 실점
- 이닝 도중 강판하면 남긴 주자가 불펜 때 들어온 실점은 내 실점 (먼저 들어온 주자부터 내 책임, 이닝 종료 시 소멸).
  M5-3 시상 공정성 검증에서 이 실점이 빠져 내 선발 ERA 가 같은 OVR NPC 보다 0.7~0.9 낮아 사이영을 쉽게 받았다

### 2.5 내 선수 — 마무리(CP)
- 9회 이후 내 팀 수비 이닝 시작 시점에 1~3점 리드(세이브 상황) 또는 동점이면 등판, 1이닝만 투구
- 점검 등판(`CLOSER_TUNE_UP`): 점수와 상관없이 9회 등판 / 휴식(`NONE`): 등판 없음 — 어느 쪽인지는 시리즈 단계(5단계)에서 연투·휴식일로 정한다
- 세이브: 리드를 지키고 승리 / 블론세이브: 리드를 잃음 (이후 팀이 이기면 구원승, 지면 패) / 동점 등판 후 팀 승리 시 구원승

### 2.6 하이라이트
- 타자: 홈런(솔로~만루, 역전·동점·끝내기 표시), 역전·동점·끝내기 적시타, 3안타·4타점·멀티홈런 경기, 보살, 도루 저지
- 투수: "6이닝 2실점 8탈삼진 퀄리티스타트 · 승리투수", 8탈삼진 이상이면 구종 이름을 넣은 문구, 세이브·블론세이브·구원승

### 2.7 아직 단순화한 부분 (밸런스 단계에서 필요하면 보강)
- 4아웃 세이브(체력 높은 CP의 8회 2사 투입)는 미구현
- 홀드, 비자책점, 주자별 책임 실점 없음
- 상대 팀 선수 개별 기록은 계산하지 않음
## 3. 출전 판정·타순·투수 운용·부상 (4단계 완료)

> 코드: `com.mlbgame.simulation.rules` — `LineupRules`, `PitcherUsage`, `Fatigue`, `Condition`, `InjuryRules`

### 3.1 타자 출전 판정 (`LineupRules`)
| OVR − 소속 레벨 평균 | 입지 | 경기별 선발 확률 |
|---|---|---|
| 0 이상 | 주전 | 100% (피로도 80 이상이면 휴식일) |
| −6 ~ 0 | 플래툰 | 75% + 차이 × 6% (−3 → 57%, −6 → 39%) |
| −6 미만 | 벤치 | 15% |

- 선발이 아닌 경기는 50% 확률로 대타 대기(7회 이후 1타석), 나머지는 결장
- 레벨 평균: 루키 35 / A 45 / AA 52 / AAA 58 / 메이저 65

### 3.2 자동 타순
- 성향: 주력형(주력·도루·선구안) / 컨택형(컨택·삼진 회피) / 파워형(파워·갭 파워) 중 평균이 가장 높은 쪽

| 입지 | 주력형 | 컨택형 | 파워형 |
|---|---|---|---|
| 주전 상위 (+8 이상) | 1번 | 3번 | 4번 |
| 주전 중위 (+3~8) | 1번 | 2번 | 5번 |
| 주전 하위 (0~3) | 9번 | 6번 | 6번 |
| 플래툰 / 벤치 | 7번 / 8번 | | |

- 포수는 한 자리 아래 (9번은 그대로)

### 3.3 투수 운용 (`PitcherUsage`, 불변 상태 객체)
- **선발**: 마지막 선발 후 5경기째 등판(5인 로테이션, 시리즈 사이 이동일은 세지 않음 → 시즌 약 32선발). 회복력 40 미만이면 +1경기, OVR 이 레벨 평균보다 6 넘게 낮으면 +1경기(6선발)
- **마무리**
  - 3일 연속 등판 금지 (시리즈 사이 이동일에 연투 기록 초기화)
  - 전날 투구 수 ≥ 25 + 회복력/5 (회복력 65 → 38구)이면 휴식
  - 4경기 이상 등판이 없으면 점검 등판
  - 연투 페널티: 연속 등판 일수 × 3 × (100 − 체력)/50 (체력 65 → 하루당 −2.1, 90 → −0.6)

### 3.4 컨디션·피로 (`Condition`, `Fatigue`)
- 컨디션 5단계(시리즈마다 랜덤): 최악 −4 / 나쁨 −2 / 보통 0 / 좋음 +2 / 최상 +4 (확률 10/20/40/20/10%)
- 피로도 0~100 (경기 출전으로만 증가, 훈련과 무관)
  - 증가: 타자 선발 +4 / 대타 +1 / 선발투수 10구당 +3 / 마무리 등판 +8 — 내구성 10당 ±8%
  - 회복: 출전 안 한 경기 −10 / 시리즈 사이 −8 — 내구성 10당 ±8%
  - 70 초과 시 경기력 −5, 부상 위험 약 2배
- 경기력 보정 = 컨디션 + 피로 페널티 → `UserHitter.formOffset` / `UserPitcher.formOffset` 로 들어간다

### 3.5 부상 (`InjuryRules`)
| 항목 | 값 |
|---|---|
| 기본 확률 (출전 경기당) | 타자 선발 0.25% / 대타 0.08% / 선발투수 1.2% / 마무리 0.4% |
| 내구성 보정 | 로그 오즈 −0.35 × (내구성 − 65)/10 |
| 피로 70 초과 | 로그 오즈 +0.7 |
| 심각도 | 경미 65% (1~3시리즈) / 중상 30% (5~20시리즈) / 시즌 아웃 5% |

- 기준: 내구성 65 주전 타자는 시즌당 약 0.37회, 선발투수(약 32경기)는 약 0.38회 부상 — MLB 부상자 명단 빈도 근사
- 결장 처리(시리즈 스킵, 훈련 +1 유지)는 M3
## 4. 시리즈·시드 저장 (5단계 완료)

> 코드: `com.mlbgame.simulation.series.SeriesSimulator`, 저장: `com.mlbgame.season.SeriesRecorder`

### 4.1 시리즈 진행 순서 (난수 사용 순서 고정)
1. `SplittableRandom(seed)` 생성 — 시리즈 전체가 이 난수열 하나만 사용
2. 컨디션 판정 (시리즈 동안 유지)
3. 경기마다 (3경기)
   1. 출전 판정 — 타자: `LineupRules` 입지·타순 / 투수: `PitcherUsage` 로테이션·연투 (+ 마무리 연투 페널티)
   2. 경기 진행 (`GameSimulator`)
   3. 피로도·등판 상태 갱신
   4. 부상 판정 — 부상이 나면 남은 경기는 결장
4. 결과: 경기별 결과, 승패, 내 선수 시리즈 합계, 컨디션, 종료 피로도·등판 상태, 부상, 하이라이트("2차전 7회말 역전 투런 홈런!")

다음 시리즈로 넘길 때는 `SeriesSimulator.carryOver()` — 이동일 피로 회복(−8), 마무리 연투 기록 초기화.

### 4.2 엔진 입력은 엔티티가 아닌 스냅샷
- `PlayerSnapshot`: 포지션, 투타, 능력치 11개, 구종 — 시리즈 시작 시점 값
- `SeriesInput`: 시드 + 레벨 + 홈 여부 + 팀·상대 전력 + 스냅샷 + 시작 피로도·등판 상태
- 이후 훈련으로 능력치가 바뀌어도, 저장된 스냅샷으로 과거 시리즈를 그대로 재현할 수 있다

### 4.3 저장 구조 (`series_records`, V8)
| 컬럼 | 내용 |
|---|---|
| player_id, season_year, series_no | 어느 선수의 몇 시즌 몇 번째 시리즈 (유니크) |
| seed, league_level | 조회·디버깅용으로 따로 보관 |
| input_json | `SeriesInput` 전체 (약 0.5KB) |
| wins, losses | 시리즈 승패 |
| summary_json | `SeriesSummary`: 내 선수 시리즈 기록 합계, 컨디션, 종료 피로도, 부상 (약 1.5KB) |

- 하이라이트·경기별 박스스코어·타석 로그는 **저장하지 않음** → `SeriesRecorder.replay(id)` 로 다시 계산
- 저장량 추정: 시리즈당 약 2KB × 54시리즈 × 20시즌 ≈ 선수당 2MB 이내

### 4.4 재현 보장 규칙 (코드 수정 시 주의)
- 엔진 안에서는 `SeriesInput.seed` 난수열 외의 랜덤(`Dice`, `Math.random` 등)을 쓰지 않는다
- 난수를 쓰는 순서를 바꾸거나 밸런스 수치를 바꾸면 **과거 시리즈의 재현 결과가 달라진다** → 요약(summary_json)은 저장해 두었으므로 시즌 기록은 유지되고, 상세 화면만 달라질 수 있다
- 필요해지면 `SeriesInput` 에 엔진 버전을 넣어 구버전 엔진으로 재현하는 방식으로 확장
## 5. 밸런스 검증 테스트 (6단계 완료)

> 코드: `src/test/java/com/mlbgame/simulation/balance` — `SeasonHarness`(시즌 반복 도구), `BalanceVerificationTest`

### 5.1 실행
```
gradlew.bat balanceTest
```
- 일반 `test` 에서는 빠져 있음 (`@Tag("balance")`) — 시즌 200회 × 8종 선수라 수십 초 이상 걸릴 수 있음
- 실행하면 콘솔에 OVR별 시즌 평균 리포트 표(타율·출루율·장타율·홈런·K%·BB%, ERA·WHIP·K/9·이닝·세이브 등)를 출력

### 5.2 시즌 반복 방식
- 54시리즈 × 3경기, 시리즈마다 새 시드, 상대 전력은 레벨 평균 ±3
- 피로·등판 상태를 시리즈 사이에 이어 가고, 부상이 나면 결장 시리즈만큼 건너뜀
- 능력치는 시즌 내내 고정 (훈련 효과 없음 — 순수한 능력치 대비 기록 확인용)

### 5.3 검증 항목과 허용 범위
| 항목 | 기준 | 허용 범위 |
|---|---|---|
| OVR 65 타자 (메이저) | MLB 리그 평균 | 타율 .232~.262 / 출루율 .300~.335 / 장타율 .370~.435 / 600타석 홈런 14~25 / K% 20~25 / BB% 7~10 |
| OVR별 OPS | 단조 증가 | 45 < 55 < 65 < 75 < 85, OVR 65 는 .680~.770, OVR 85 는 .900 초과 |
| 출전 | 입지 반영 | 주전(OVR 75) 시즌 560~720타석, 벤치(55·45)는 주전의 40% 미만 |
| 시즌 편차 | 운의 영향 | 주전 시즌 타율 표준편차 .010~.035 |
| 레벨 적합 | 상대적 기록 | 각 마이너 레벨 평균 OVR 선수의 OPS .660~.790 |
| 수비 | 능력치 반영 | OVR 85 의 막은 실점 > 0, OVR 45 보다 큼 |
| 부상 | MLB 빈도 근사 | 주전 시즌 0.15~0.7회, 선발투수 0.15~0.8회 |
| OVR 65 선발 | MLB 평균 선발 | 선발 26~36회 / 130~200이닝 / ERA 3.6~5.0 / K/9 7.5~9.8 / BB/9 2.5~3.9 / HR/9 0.8~1.5 |
| OVR 80 선발 | 에이스 | ERA 가 평균보다 0.5 이상 낮고, 이닝·승수 많음 |
| OVR 65 마무리 | MLB 평균 마무리 | 등판 40~80 / 세이브 15~45 / 등판당 1이닝 이하 / ERA 3.0~5.2 |

### 5.4 보정 이력
| 차수 | 결과 | 원인 | 조치 |
|---|---|---|---|
| 1차 | OVR 65 타율 .230·OPS .673 (기준 미달) | 우타자가 우완(72%)을 만날 때마다 같은 손 페널티 −0.10 → 평균 −0.06 치우침 | 같은 손 페널티를 −0.05 로, 반대손 이점은 투수 좌우 대응 65 기준으로 → 평균 보정 ≈ 0 |
| 1차 | 루키리그 평균 OVR 선수 OPS .556 | 타자·투수 계수 합이 달라(예: 홈런 0.35 vs 0.25) 능력치가 같아도 낮은 레벨일수록 공격이 약해짐 | 사건별 타자 합 = 투수 합으로 계수 재조정 (BABIP 에 무브먼트, 2루타에 땅볼 유도 계수 추가) |
| 1차 | 선발 시즌 39선발·225이닝 | 이동일까지 로테이션 간격에 셈 (215일 / 5) | 이동일 제외 → 162경기 / 5 ≈ 32선발 |

### 5.5 범위를 벗어나면
- 타격 비율이 어긋나면 `game.simulation.baseline` (기준 비율) 또는 `coefficients` (능력치 영향력) 조정
- 득점·이닝·투구 수가 어긋나면 `GameSimulator` 의 주루 확률·투구 수 상수 조정
- 출전·부상이 어긋나면 `LineupRules`·`InjuryRules` 상수 조정
- 조정 후에는 과거 시리즈의 재현 결과가 달라질 수 있음 (4.4 참고)
